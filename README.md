описание:
Система — мультимодальная оценка суицидального риска по медиа (в первую очередь видео). Пользователь загружает видео. Система делает препроцессинг: извлекает аудио, распознаёт речь и получает текст (ASR → transcript). Далее текст анализируется NLP-моделью и возвращается риск-скор и/или вердикт.

На данный момент end-to-end подтверждённо работает только NLP-модель: видео → аудио → транскрипт → анализ → риск-скор. Это проверено и даёт результат.

CV-модель в проекте присутствует (код и/или веса добавлены), но в текущей интеграции не работает: при запуске пайплайна CV-результат не получается (модель не запускается, не грузится или падает/пропускается). Поэтому сейчас общий результат формируется только на базе NLP.

В проекте также предусмотрены дополнительные модели (в сумме до 8) и финальная 9-я модель-агрегатор, которая позже будет объединять сигналы от всех моделей в единый финальный скор/вердикт. Часть моделей требует аудио сегменты длительностью 3–13 секунд, часть использует face images, часть работает по тексту открытых вопросов. На выходе система должна давать финальный риск суицидальных наклонностей (score + verdict).
